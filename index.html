This tool runs locally — your data stays with you

This is an open-source viewer published on GitHub and can be hosted as a GitHub Page. Files you select (message JSON or media folders) are processed entirely in your browser — nothing is uploaded or sent to any server by this application. The tool does not collect or transmit your messages, media, or metadata under any circumstance.

If you'd prefer extra caution, you can download the repository and run the page offline (open the HTML file locally) or host it yourself. For full transparency the source code is available on GitHub.
